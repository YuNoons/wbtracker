# 🛡️ AGENT RULES — Правила Разработки WB Tracker (v1.3)

Данный документ описывает фундаментальные ограничения и правила для всех ИИ-агентов при разработке приложения **WB Tracker**.

---

## 🚫 1. Фундаментальные Запреты (Strict Constraints)
1. **Приложение 100% бесплатно**: Никаких Pro-подписок, платных функций, paywall или рекламы.
2. **Никаких новых табов в навигейшн-баре**: Нижняя панель навигации строго содержит 4 таба + центральный FAB:
   `Главная | Избранное | [+] | Аналитика | Профиль`
3. **Уведомления (Alerts)**: Открываются строго через Bottom Sheet по клику на колокольчик `🔔` в верхнем баре (НЕ как новый экран/таб).
4. **Onboarding**: Показывается строго 1 раз при первом запуске приложения (3 коротких экрана). Никогда не выводится повторно при обычных запусках.
5. **Экспорт и Бэкап**: Размещаются строго в Профиле в секции "Данные" (CSV, JSON, локальное резервное копирование).
6. **Theme Packs**: Спрятаны в `Профиль -> Внешний вид`. По умолчанию активен стиль **Premium Finance Dark**.
7. **Максимум 1 активный баннер на экране**: Запрещено засорять экран несколькими баннерами.
8. **Эргономика тач-зон**: Все кликабельные элементы должны быть размером не менее $48\times 48\,\text{dp}$.
9. **Оптимизация 60 FPS**:
   - `backdrop-filter` разрешен ТОЛЬКО для верхнего бара, нижнего навбара, тостов и оверлеев. Запрещен на каждой карточке списка!
   - Анимации strictly через CSS `transform` и `opacity` (GPU composite layers).
   - Canvas-графики не перерисовываются без надобности.
10. **НЕТ тяжелым блокировкам UI**: Все длительные операции в `WbBridge.kt` выполняются асинхронно.

---

## 📐 2. Стандарты Кода и Модульности
- Фронтенд декомпозирован на модули:
  - `css/tokens.css` (дизайн-токены, отступы, шрифты)
  - `css/themes.css` (палитры тем и стилей)
  - `css/components.css` (компоненты: карточки, кнопки, чипы, шторки)
  - `css/screens.css` (макеты экранов)
  - `js/bridge.js` (мост взаимодействия с Kotlin)
  - `js/state.js` (управление состоянием)
  - `js/charts.js` (Canvas движок графиков)
  - `js/ui-*.js` (модули экранов и фичей)
