### 🔋 Этап 1 (Разделы 1-2): Нативный Запрос Игнорирования Оптимизации Батареи Android & Фоновый `WorkManagerScheduler`

#### 1.1. Нативный Запрос Игнорирования Оптимизации Батареи (`REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`)
- **Проблема**: Операционная система Android в режиме энергосбережения / Doze Mode замораживает фоновые фоновые задачи `WorkManager`, срывая расписание автоматической проверки цен товаров Wildberries 24/7.
- **Решение**:
  1. Добавить разрешение в `AndroidManifest.xml`:
     ```xml
     <uses-permission android:name="android.permission.REQUEST_IGNORE_BATTERY_OPTIMIZATIONS" />
     ```
  2. В [`MainActivity.kt`](file:///home/yura/projects/wbtracker/app/src/main/kotlin/com/wbtracker/app/MainActivity.kt) добавить системную проверку статуса оптимизации через `PowerManager.isIgnoringBatteryOptimizations(packageName)`.
  3. Добавить нативные методы в [`WbBridge.kt`](file:///home/yura/projects/wbtracker/app/src/main/kotlin/com/wbtracker/app/bridge/WbBridge.kt):
     ```kotlin
     @JavascriptInterface
     fun isBatteryOptimizationIgnored(): Boolean

     @JavascriptInterface
     fun requestBatteryOptimizationExemption()
     ```
  4. В `index.html` на Главной странице (`#screen-dashboard`) и на экране Профиля (`#screen-profile`) вывести желтую предупреждающую плашку-баннер: *"Разрешите фоновую работу для обновления цен 24/7"*, с кнопкой "Разрешить", вызывающей нативный диалог назначения белого списка питания Android.

#### 1.2. Перепланирование и Снятие Спама Уведомлений в `WorkManagerScheduler`
- При смене интервала синхронизации в Профиле (1, 3, 6, 12, 24 ч) мгновенно обновлять расписание через `ExistingPeriodicWorkPolicy.UPDATE`.
- При отправке Push-уведомления об измерении цены в [`PriceUpdateWorker.kt`](file:///home/yura/projects/wbtracker/app/src/main/kotlin/com/wbtracker/app/data/worker/PriceUpdateWorker.kt) ставить отметку `isActive = false` для сработавших правил, предотвращая спам до повторной активации пользователем.

### 🎨 Этап 2 (Разделы 3-4): Дизайн-Система v1.3, Переработка Hero Card & Семантические Цвета

#### 2.1. Семантическая Палитра Цветов v1.3
- **Зеленый (Снижение цены / Экономия)**: `#059669` (Emerald 600) — используются для отображения экономии, падающей цены и положительных статусов.
- **Оранжевый (Рост цены / Предупреждения)**: `#D97706` (Amber 600) — используются для предупреждающих статусов роста цены и плашек целевой цены Target Price.
- **Фиолетовый (Акценты / Бренд / Графики)**: `#7C3AED` (Purple 600) — фирменный цвет приложения, активных элементов и брендовых кнопок.

#### 2.2. Модернизация Hero Card Совокупной Экономии
- **Большая сумма с анимацией Count-Up**: анимация набора цифр суммы экономии `hero-savings-val` при старте и обновлении (от 0 до финального значения в рублях за 800ms).
- **Спарклайн 7 дней**: миниатюрный трендовый Canvas-график последних 7 дней внутри блока Hero Card без координатных осей.
- **Метрики товаров**: вывод числа активных отслеживаний и количества снижений цен.

### 📊 Этап 3 (Разделы 5-6): Интерактивный Canvas-График Цен & Touch Scrubber

#### 3.1. Touch Scrubber при Касании Пальцем
- Реализация интерактивного визира при ведении пальцем по Canvas-графику (`touchstart`, `touchmove`, `pointermove`).
- Отрисовка вертикальной направляющей пунктирной линии под пальцем.
- Динамический инспектирующий Floating Tooltip: выводит дату (например, `"14 авг, 12:45"`) и цену по WB Кошельку (например, `"4 250 ₽"`).

#### 3.2. Пунктирная Линия Целевой Цены (Target Price)
- Отображение горизонтальной пунктирной линии уровня целевой цены `targetPrice` (`ctx.setLineDash([4, 4])`) оранжевым семантическим цветом `#D97706`.

#### 3.3. Переключение Диапазонов Графика (7д / 30д / Всё время)
- Чипы переключения временных интервалов графика в Детализации товара.
